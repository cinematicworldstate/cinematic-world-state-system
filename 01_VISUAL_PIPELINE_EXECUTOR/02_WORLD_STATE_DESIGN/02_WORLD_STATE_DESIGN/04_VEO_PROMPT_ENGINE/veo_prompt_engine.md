MASTER LAWS — READ BEFORE EVERY OUTPUT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PRIORITY LAW — when instructions conflict, resolve in this order:
1. Scene clarity — dominant action instantly readable
2. Character identity — same face as Clip 0 description — no drift
3. Physical realism — weight, friction, material behavior correct
4. Action readability — what is happening is unambiguous
5. Lip-sync + voice — if dialogue exists, protect facial integrity first
6. Composition — frame serves the action
7. Secondary details — support, never compete
8. Style language — last, never overrides above

TOKEN ECONOMY LAW:
Use fewest words for strongest result.
Concrete nouns and verbs. Delete adjectives that duplicate a noun.
If two instructions say the same thing — keep the more specific one.

VISIBLE-ONLY LAW:
Direct only what can be seen or heard.
No lore. No symbolic description. No unseen causes.
If Veo cannot render it — remove it.

MODEL UNCERTAINTY LAW:
No pseudo-technical precision unless it changes output.
No fake lens values or percentages unless visually meaningful.

DOMINANT SUBJECT LAW:
One instantly readable primary action per clip.
Secondary motions support — never compete.

MOTION BUDGET LAW:
Maximum 3 simultaneous meaningful motions:
1. Primary subject motion
2. Secondary support motion (one element only)
3. Environmental motion (one element only)
Everything else locked. Stable. Does not move.
More than 3 = chaos = morphing artifacts.

SPEECH PRIORITY LAW:
If dialogue exists in clip — facial integrity + lip-sync + voice clarity
override all other motion complexity.
Reduce background motion. Reduce camera movement. Protect the face.

PHYSICS FILTER:
Reject floaty, frictionless, rubbery, weightless motion.
Every motion has: surface resistance + body weight + committed direction.
If motion description could apply to zero-gravity — rewrite it.

ENDING FRAME LAW:
Final 1.5s must feel intentionally concluded.
Not abruptly cut. Not looping randomly.
Zone 3 = motion settles or completes — not freezes.

ARTIFACT RECOVERY LAW:
If generation artifacts appear — remove lowest-priority secondary motion first
before adjusting primary action. Never sacrifice primary driver to fix artifacts.

SIMPLICITY OVERRIDE:
If scene feels over-constrained — reduce secondary motion first, simplify camera second,
keep primary action + character identity above all else.

VOICE BIBLE SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Veo infers voice from character description + physical state + tone modifier.
"Mid-register / roughened at edges / slight dryness" = invisible to Veo — do not use.
What actually works: Age + Gender + Timbre + Tone + Pacing + Acoustic environment.

VOICE BIBLE — set ONCE at sequence start:
"A [exact age]-year-old [gender] with a [timbre 1] and [timbre 2] voice.
[He/She] speaks in a [tone] tone at a [pacing] pace.
Native Hindi speaker — natural Hindi prosody — no compression."

Copy this VERBATIM into every clip. Never paraphrase. One different word = voice drift.

TIMBRE — pick 2, keep identical every clip:
gravelly / smoky / warm baritone / deep resonant / rough dry /
soft breathy / crisp articulate / low husky / coarse-grained / tight controlled

TONE — pick 1, keep identical every clip:
weary / quietly intense / cold controlled / calm deliberate /
resigned / measured / suppressed / tired authority / strained composed

PACING — pick 1, keep identical every clip:
slow and deliberate / measured with natural pauses /
unhurried — words arrive without rush / clipped efficient /
controlled — each word costs something

ACOUSTIC ENVIRONMENT — set ONCE — copy verbatim every clip:
OPEN AIR/FIELD  → "voice in open air — no wall reflection — dissolves at 2-3m — no echo"
STONE/ENCLOSED  → "voice in enclosed stone — short flat echo — low reverberation"
WOOD STRUCTURE  → "voice in timber space — slight hollow resonance — high freq absorbed"
CROWD/OUTDOOR   → "voice cutting through ambient — each word deliberate — crowd present"

PHYSICAL STATE WEIGHT — ONLY this changes per clip:
HEAVY   → breathing through effort — each word costs physically
MEDIUM  → controlled breath — words measured — effort managed
LIGHT   → steady breathing — unhurried — words arrive without cost
TENSE   → held breath released before speaking — words clipped
SHOWING → deliberate pacing — words timed with gesture

Tone word in dialogue = MUST MATCH tone word in Voice Bible — never substitute synonym.
Physical state = only intentional change — matches PHYSICAL_STATE_WEIGHT input field.
