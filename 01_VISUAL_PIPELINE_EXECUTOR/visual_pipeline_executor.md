CHARACTER ACTION LAW:
The character performs the action the
script line requires.
The character does not watch someone
else perform it.
The character does not describe it
abstractly from a distance.
Character state must match script
line verb:
— Script line describes character
  performing an action →
  DOING state mandatory
— Script line describes character
  observing a result →
  WATCHING permitted

  presenting an object →
  SHOWING permitted

CONSEQUENCE — what the action costs
              the body in this moment

              from it"

smoothly / steadily / carefully /

by a machine?"

consequence absent →

proceed.

MOTION REWRITE TRIGGER:
Any Scene Description motion sentence

PHYSICAL CONSEQUENCE CHAIN LAW:
Before writing Scene Description,
lock the chain from script action.
This chain is not added — it is
extracted from the physics of the
primary action only.

Fill this before writing:

PRIMARY:
What force is acting on what material?
How does that material behave
in physical reality?

CONSEQUENCE 1:
What changes immediately and directly
because of that force —
same material system, same location,
no new cause introduced?

CONSEQUENCE 2:
Where does that effect reach next —
adjacent surface or adjacent space —
following physics alone,
not camera logic?

HUMAN TASK:
Who was already working in this space
before the primary action began?
What specific task were they doing —
specific to this location and era —
with its own physical resistance?
How does Consequence 1 or 2
physically reach their task or their
body — without them deciding
to respond?

CHAIN RULES:
— Every step must follow from the
  previous by physics alone —
  no human decision, no camera choice
— Chain originates from
  script-required primary action
  only — do not invent a new cause
— Human task must have existed before
  primary action began —
  not inserted for the scene
— Interference with human task must
  be involuntary — physics acting on
  body or work surface —
  not a decision

CHAIN CAP — maximum per Scene
Description foreground content:
1 primary action
+ 1 immediate consequence
+ 1 secondary consequence
+ 1 independent human task
  physically disturbed by chain

CHAIN CAP SCOPE:
This cap governs foreground and
midground physical content only.
Chaos element = imperfection within
primary action — not a separate
element — does not count toward cap.
Micro Action = background element —
not foreground — does not count
toward cap.
Background Confirmation = world
element — governed by Section 3 —
does not count toward cap.
Cap violation = adding a SECOND
primary consequence chain or a
SECOND independent human task.
More than cap = exaggeration =
CHAIN OVERFLOW VIOLATION →
remove until cap is met.

PARTIAL VISIBILITY RULE:
At least ONE consequence in the chain
must be partially off-frame,
at edge of frame,
or obscured by a foreground element.
Full visibility of all consequences
= designed for camera = REWRITE.

CHAIN TEST — runs after writing:
"Does each step in the chain follow
from the previous by physics alone
without any human decision or
camera placement choice?"
YES → chain real → proceed.
NO → chain invented →
remove invented step →
find real physical next step.

ANTI-EXAGGERATION RULE:
If any effect in the chain feels
instant, clean, or perfectly visible:
→ add delay to it
→ add resistance to it
→ make spread uneven
→ reduce scale of effect
Perfect effect = staged effect =
REWRITE.

ANTI-EXAGGERATION SCOPE:
Applies to consequence chain
propagation — the spread and reach
of effects through the chain.
Does NOT apply to the primary force
event itself.
Primary impact can be immediate and
decisive — it is the chain effects
that must show delay, resistance,
and uneven spread.
Spike = primary force consequence
at scale = exempt from
anti-exaggeration rule.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

THIS IS A RENDERING INSTRUCTION BLOCK.
It does not direct scenes.
It does not override pipeline logic.
It tells the image model how
physical reality looks in this style.
Scenes are directed by Script Line
→ SCENE PRE-WRITE LAW only.

IMAGE-TO-VIDEO:
All rules in this block apply to
every frame of the clip continuously.
Light source direction does not
shift mid-clip.
Depth layer relationships do not
change mid-clip.
Palette and shadow rules hold from
Frame 1 to final frame — no drift.

PALETTE:
Muted — desaturated but alive.
Not grey. Not washed.
Midtones carry the image.
Saturated color = WRONG.
Desaturated to grey = WRONG.
Target: color exists but never
announces itself.

LIGHT SOURCE:
Single source only — always.
That source must physically exist
in the location described.
No fill light. No bounce.
No secondary motivated source.
Shadows fall where physics places
them — not where drama needs them.

SOURCE TYPE — derive from location:
Fire / lamp / torch → amber point
source → hard shadow one direction
→ warmth on surfaces facing source
→ everything else in shadow falloff

Window / aperture → directional soft
→ one wall lit → opposite wall dark
→ no wrap-around

Overcast sky → flat top light →
soft shadows directly below →
no directional drama

Direct sun → hard single direction
→ strong shadow → not overhead →
angle from ERA RESEARCH time of day

LIGHT DIRECTION:
Side-left or side-right relative
to subject — NEVER front-flat.
Front-flat = documentary = WRONG.
Side light = one surface lit,
opposite in falloff shadow.
This separation is what creates
depth without adding elements.

EXPOSURE FEEL:
Not underexposed — shadow detail
present.
Not overexposed — highlight detail
present.
Midtones exposed correctly —
everything else falls naturally.
If it looks lit → WRONG.
If it looks shot → CORRECT.

CONTRAST AND SHADOW:
Present — not crushed.
Blacks: lifted slightly — shadow
detail visible — surface texture
readable in darkest frame area.
Highlights: not blown — texture
visible in brightest surface.
Not flat — not theatrical.
Contrast comes from single source
falloff — not from grading choice.

SHADOW AS DEPTH:
Shadow is not absence of light.
Shadow is the most information-dense
part of the frame.
Shadow must show:
— surface texture (lifted blacks —
  detail present)
— depth (shadow falls differently
  on FG than MG than BG)
— light source direction (shadow
  angle tells viewer where source
  is without showing the source)

TEST per clip:
"Can I read the surface texture
of the darkest area in frame?"
YES → shadow correct → proceed.
NO → blacks crushed → SHADOW
VIOLATION → lift shadow detail.

TEXTURE RULE:
Every surface in frame must show
physical history.
Smooth = WRONG.
Perfect = WRONG.
Worn / aged / used = CORRECT.
Texture visible in shadows —
not just in highlights.

LENS FEEL — rendering instruction
derived from SHOT TYPE this clip.
Not a new creative decision.
Not chosen for mood.
Chosen because this is what
physical readability requires
at this distance.

ECU (100–135mm rendering):
Camera at 15–30cm from primary
contact point.
Surface texture IS the subject.
Background irrelevant — completely
soft — color only, no readable form.
Light rakes ACROSS surface —
not flat onto it — micro-shadows
readable in texture.
Character: hands and tool only
OR face and object — never full
body at ECU.
NOT a beauty macro shot —
texture must be actively changing,
resisting, or failing.

CU (85mm rendering):
Camera at 40–80cm from face or
primary working hand.
Subject sharp — immediate background
soft — environment implied not shown.
Slight background compression —
subject separates cleanly —
NOT theatrical stacking.
Individualizing detail visible.
Effort readable in jaw, shoulder,
hand grip.
Eyes on task — not camera.

MEDIUM (50mm rendering):
Camera at 1–2m from subject.
Subject and immediate environment
in honest proportion — no compression
no expansion — space reads as real.
Something happening in every layer
simultaneously.
NOT a coverage shot.

WIDE (35mm rendering):
Camera at 4–8m from subject.
Space reads at true physical distance
— expansive — real — not stretched.
Character fills 15–25% of frame —
small but specific —
individualizing detail still readable.
Single source light rakes across
environment showing full depth.
NOT establishing shot —
action already in progress.

FULL SCALE (28–35mm rendering):
Camera at 15m+ from subject.
Background at true physical distance
— breathable — world witnessed
not designed.
One specific physical event dominates
center frame.
Character at far background edge —
silhouette or near-silhouette.

BANNED LENS FEEL ENTIRELY:
— 200mm+ telephoto compression:
  background stacked into subject —
  designed feel — GOT territory —
  BANNED at all scales
— 24mm or wider except at
  architectural FULL SCALE only
— Any lens feel chosen for
  "cinematic mood" rather than
  physical readability of action

DEPTH:
Always three layers minimum —
foreground / subject / background.
Each layer at different focus plane.
Never all sharp — never all soft.
Foreground element: slightly soft
or at frame edge — physically present
in location — NOT decorative.
Subject: sharp.
Background: soft at LOCAL/ISOLATED —
atmospheric at EXPANDED/FULL SCALE.

DEPTH SEPARATION — three methods:
Focus falloff: foreground sharp,
background soft by distance.
Light falloff: single source means
FG receives light differently than
MG which receives differently than
BG — each layer reads differently.
Atmospheric: distance creates haze
at EXPANDED/FULL SCALE.
Use all three when possible.
Minimum: two methods per clip.

WIDE LAYOUT:

frames the action
MG: character + mechanism — sharp —

SUBJECT PLACEMENT:
Subject faces INTO the larger
portion of frame.
Subject on left third → faces right.
Subject on right third → faces left.
Centered ONLY if action requires
symmetry.
Asymmetric placement = depth =
correct.
Centered default = designed = WRONG.

MOVEMENT FEEL:
Camera movement must feel like
it followed the action —
not like it was planned for the
action.
Slow Push = operator following
subject — not dramatic reveal.
Slow Pull = world revealing itself
— not hero moment.
Locked = action is enough —
camera has no opinion.

WHAT THIS STYLE IS NOT:
Not documentary flat — depth and
texture prevent flatness.
Not epic drama — single source and
muted palette prevent theatrics.
Not robotic — imperfection in
environment and action prevent
sterility.
Not polished — worn surfaces and
real shadow prevent glossiness.
Not GOT — no telephoto compression,
no theatrical motivated lighting,
no hero composition.

TEST per clip:
"Does this look like it was shot
or does it look like it was made?"
SHOT → CORRECT.
MADE → WRONG → identify what is
too perfect → add wear /
imperfection / shadow detail.

remove it.
Palette saturated → mute it.
Blacks crushed → lift shadow detail.
Highlights blown → recover texture.
All surfaces clean → add wear.
Telephoto compression present →

SHOT TYPE.

readability → re-derive from
SHOT TYPE.

element physically present in
location.
"Made not shot" feel → identify
most perfect element → break it.
